ABOUT

The short version

Most of what I make sits between a messy data source and a person who needs to act. A class of ninety students produces hundreds of attendance rows, but the only question that matters is whether you can afford to skip Thursday.

My day-to-day is Python and SQL, with Java and machine learning taking more of my time lately. I lean on AI tooling as a reasoning layer I design prompts and fallbacks around — so the thing still works when the model returns something unexpected.

I care most about the unglamorous part: what happens when the API rate-limits, when the model returns broken JSON, when someone opens the page with no network. Building the fallback path first is what makes the happy path worth trusting.
